1 · Qué es Flashir

Flashir es un lenguaje interpretado en español pensado para convertir ideas visuales en programas cortos y fáciles de leer.

Objetivo

La unidad principal de ejecución es un programa Flashir escrito dentro del editor. El programa se convierte en tokens, luego en un árbol sintáctico y finalmente es ejecutado por un intérprete que dibuja sobre Canvas 2D.

El diseño prioriza una relación directa entre código y resultado visual. Una instrucción como circulo(300,200,50,"azul") no describe una abstracción distante: ordena dibujar inmediatamente una figura en el lienzo.

El mismo lenguaje puede expresar estado, reglas, interacción y renderizado, de modo que un juego no necesita cambiar a otro lenguaje para implementar su lógica.

Qué tipo de proyectos permite

Dibujos estáticos, animaciones, juegos 2D, prototipos de física, tableros, interfaces, visualizaciones científicas, simuladores de partículas y experiencias point-and-click son usos naturales.

Para juegos complejos conviene pensar el programa como tres capas: estado del mundo, actualización por fotograma y renderizado. Flashir tiene las primitivas necesarias para mantener estas tres capas dentro de un solo archivo.

Idea central

El lenguaje es deliberadamente pequeño en sintaxis, pero amplio en capacidad práctica. La potencia aparece al combinar funciones propias, listas, objetos, bucles, entrada, tiempo, colisiones, geometría y Canvas.

fondo("#101014");
circulo(300,200,80,"azul");
textoCentrado(300,330,"Hola desde Flashir",24,"blanco");

2 · Arquitectura del runtime

La implementación actual mantiene una arquitectura de compilación ligera que resulta fácil de extender.

Flujo

El lexer recorre el código carácter por carácter y produce tokens con tipo y línea. Reconoce números, cadenas, identificadores, operadores y delimitadores.

El parser consume esos tokens y crea nodos AST para declaraciones, asignaciones, expresiones, llamadas, condicionales y bucles. El AST separa la estructura del programa del acto de ejecutarlo.

El intérprete evalúa expresiones, administra ámbitos y ejecuta instrucciones. Las funciones incorporadas conectan el lenguaje con Canvas, teclado, mouse, almacenamiento y utilidades matemáticas.

Ventaja práctica

Como el lenguaje está embebido en HTML, no necesita un compilador externo para funcionar en el navegador. El mismo archivo contiene editor, documentación, intérprete y escenario.

Esta arquitectura también permite ampliar Flashir añadiendo nuevas funciones incorporadas sin romper la sintaxis central.

código Flashir → lexer → parser → AST → intérprete → Canvas 2D + consola

3 · Comentarios, bloques e identificadores

Los programas se organizan con comentarios, instrucciones y bloques delimitados por llaves.

Comentarios

El comentario con # llega hasta el final de línea. También se acepta // para conservar una forma familiar de comentar código.

Los comentarios no generan instrucciones y son ideales para explicar reglas de juego, fórmulas o la función de una zona del programa.

Bloques

Las llaves agrupan el cuerpo de si, sino, repetir, para, mientras, para_cada, animar y funcion. Los bloques pueden anidarse.

Un punto y coma final suele ser opcional al final de una línea, aunque se recomienda utilizarlo de forma consistente en programas grandes.

Identificadores

Se permiten letras, letras acentuadas, ñ y guion bajo, además de dígitos después del primer carácter. Esto hace posible usar nombres expresivos como velocidad_horizontal o jugador_principal.

# gravedad del mundo
var gravedad = 420;

si (gravedad > 0) {
  imprimir("Mundo con gravedad");
}

4 · Valores y tipos

Flashir trabaja con números, textos, booleanos, listas, objetos y nulo.

Números

Los números sirven para coordenadas, velocidades, escalas, ángulos, puntuaciones y cualquier cálculo. Se admiten enteros y decimales.

La aritmética usa los operadores +, -, *, / y %.

Texto

Las cadenas van entre comillas dobles y pueden contener espacios y saltos de línea escapados. El operador + puede concatenar texto y valores.

Las funciones de texto permiten convertir, recortar, separar, buscar y reemplazar contenido.

Booleanos y nulo

verdadero y falso representan condiciones. nulo representa ausencia de valor y resulta útil como marcador de estado.

Las condiciones de juegos suelen combinar booleanos con &&, || y !.

Listas y objetos

Las listas representan inventarios, tableros, colas, partículas y secuencias. Los objetos agrupan propiedades relacionadas como jugador, enemigo, cámara o configuración.

var vida = 100;
var nombre = "Luna";
var vivo = verdadero;
var inventario = ["llave","moneda"];
var jugador = {nombre:"Luna", vida:100, puntos:0};

5 · Variables y ámbitos

Las variables guardan el estado del programa. Las declaraciones var, let y const forman parte de la sintaxis actual.

Declaración

var, let y const comparten la forma var nombre = expresión. El runtime actual acepta las tres palabras y no impone una inmutabilidad especial a const.

En juegos conviene declarar el estado persistente fuera de animar, de modo que sobreviva entre fotogramas.

Asignación

Una variable puede cambiar con =, +=, -=, *= y /=. ++ y -- permiten incrementar o decrementar valores numéricos de forma compacta.

El intérprete busca primero en el ámbito local y luego en ámbitos exteriores, por lo que las funciones pueden leer variables externas.

Ámbitos

Las funciones crean un ámbito local para sus parámetros y variables. Esto evita que una variable temporal de una función sustituya accidentalmente al estado global del juego.

var x = 10;
let velocidad = 4;
const anchoMundo = 1200;
x += velocidad;
x++;
FLASHIR · 7

6 · Operadores y expresiones

Las expresiones pueden combinar valores, llamadas, índices, propiedades y operadores.

Aritmética y comparación

Los operadores aritméticos siguen la precedencia habitual. Las comparaciones producen booleanos y permiten construir reglas como vida <= 0 o x > ancho.

== y != comparan valores; <, <=, > y >= comparan orden.

Lógica

&& y || usan evaluación de cortocircuito. ! invierte un booleano. Estas operaciones son la base de reglas como tecla_izquierda && puede_mover o vivo || modo_demo.

Ternario

La forma condición ? valor_si : valor_no permite elegir entre dos expresiones sin escribir un bloque completo. Resulta especialmente útil para colores, etiquetas y estados visuales.

Índices y propiedades

Una lista puede indexarse con [indice]. Los índices negativos cuentan desde el final. Los objetos pueden leerse como objeto.propiedad y el runtime también admite indexación por clave en objetos.

var estado = vida > 0 ? "VIVO" : "GAME OVER";
var color = velocidad > 0 ? "verde" : "rojo";
texto(20,40,estado,24,color);
FLASHIR · 8

7 · Condicionales

si, sino y sino si permiten construir la lógica de estados, reglas y transiciones.

Diseño de reglas

Separar condiciones pequeñas ayuda a leer un juego. Un bloque puede decidir movimiento; otro, daño; otro, estado de pantalla.

sino si evita anidar varios si y es apropiado para menús, dificultad, rangos de puntuación y estados mutuamente excluyentes.

Consejo de juegos

Conviene mantener las condiciones que cambian el estado antes de las instrucciones de dibujo. Así el renderizado representa el estado ya actualizado.

Para evitar errores de borde, limitar() puede combinarse con condiciones que protejan posiciones y velocidades.

si (vida <= 0) {
  estado = "muerto";
} sino si (vida < 25) {
  estado = "critico";
} sino {
  estado = "estable";
}
FLASHIR · 9

8 · Bucles

repetir, para, mientras y para_cada cubren los patrones de iteración necesarios para tableros, entidades y cálculos.

repetir

Es útil cuando interesa ejecutar una operación un número conocido de veces. El runtime coloca el contador i en el ámbito actual durante las iteraciones.

para

Es el patrón clásico para recorrer posiciones, filas y columnas. Para grandes tableros de juego es habitual usar dos for anidados.

El runtime tiene una guarda contra bucles excesivos para evitar congelamientos accidentales.

mientras

Sirve para simulaciones que deben avanzar mientras una condición sea cierta. Para sistemas de tiempo real suele ser mejor animar, porque animar ya sincroniza la actualización con cada fotograma.

para_cada

Recorre elementos de una lista o caracteres de un texto. Es útil para inventarios, partículas, opciones de menú y colecciones de objetos.

Control

romper abandona el bucle actual. continuar salta al siguiente ciclo.

para (var y=0; y<20; y++) {
  para (var x=0; x<10; x++) {
    rectangulo(100+x*18,30+y*18,17,17,"#20242c");
  }
}
FLASHIR · 10

9 · Funciones propias y recursión

Las funciones convierten reglas repetidas en unidades reutilizables.

Parámetros y retorno

Una función se declara con funcion nombre(parametros) { ... }. retornar devuelve un valor y corta la ejecución de esa llamada.

Una función puede ser matemática, gráfica o lógica. En juegos es habitual usar funciones como dibujarJugador, puedeMover, generarEnemigo o dibujarHUD.

Recursión

El runtime admite llamadas recursivas y limita la profundidad para protegerse de recursiones infinitas. La recursión es útil para árboles, habitaciones conectadas o algoritmos de búsqueda pequeños.

Para lógica de tiempo real conviene preferir iteración cuando el problema pueda crecer mucho, ya que resulta más predecible.

funcion factorial(n) {
  si (n <= 1) { retornar 1; }
  retornar n * factorial(n-1);
}

imprimir(factorial(5));

10 · Listas como estructura de datos

Las listas son la herramienta central para construir tableros, inventarios, partículas y datos temporales.

Acceso y edición

lista[indice] permite leer un elemento y los índices negativos cuentan desde el final. La asignación lista[indice] = valor modifica el contenido.

Para tableros bidimensionales puede utilizarse una lista plana con indice = fila * ancho + columna. Este patrón es simple, rápido y totalmente compatible con el runtime.

Utilidades

lista_agregar, lista_quitar, lista_longitud, lista_contiene, lista_vacia, lista_ordenar, lista_invertir y lista_unir cubren operaciones comunes.

Las extensiones crearLista, rellenarLista, subLista, copiarLista, lista_indice y lista_reemplazar reducen el código de preparación de grandes colecciones.

Estadística y aleatoriedad

contar, sumaLista, promedioLista, mezclarLista, indiceAleatorio y azarDeLista permiten crear sistemas de puntuación, distribuciones aleatorias y selección de entidades.

var tablero = crearLista(200, "");
tablero[0] = "azul";
tablero[199] = "rojo";
imprimir(lista_longitud(tablero));

11 · Objetos y propiedades

Los objetos permiten representar entidades del mundo con propiedades legibles.

Modelo

Un objeto puede representar un jugador, enemigo, puerta, artículo, configuración de simulación o estado de escena. La lectura objeto.propiedad mantiene el código expresivo.

Propiedades pueden modificarse con =, +=, -=, *= y /= cuando el objeto está referenciado por una variable.

API

objeto() crea un objeto vacío. poner y obtener trabajan por clave. eliminar quita una propiedad. tiene prueba su existencia. claves y valores permiten inspeccionar contenido.

tipo, esNumero, esTexto, esLista y esObjeto sirven para construir funciones defensivas y validar datos antes de operar con ellos.

Patrón de entidad

Un juego puede guardar x, y, velocidad, vida, tamaño y estado en un objeto. Aunque Flashir no obliga a utilizar una clase o sistema de componentes, los objetos permiten obtener un estilo de programación estructurado.

var jugador = {x:300,y:200,vida:100,puntos:0,estado:"normal"};
jugador.vida -= 10;
poner(jugador,"nivel",3);
si (tiene(jugador,"nivel")) { imprimir(obtener(jugador,"nivel")); }

12 · Texto y mensajes

Las funciones de texto son especialmente útiles para HUD, diálogos, inventarios y pantallas de menú.

Transformación

mayusculas y minusculas normalizan texto. recortar elimina espacios alrededor. repetirTexto duplica un texto un número dado de veces.

subTexto, caracter, empiezaCon, terminaCon e incluye permiten construir pequeños analizadores o sistemas de diálogo.

Conversión y separación

textoANumero convierte una cadena numérica en número y numeroATexto realiza la conversión inversa. separar divide una cadena en una lista mediante un separador.

unir concatena una lista de valores en un texto.

Aplicaciones

Un juego narrativo puede construir mensajes con datos del jugador. Un simulador puede mostrar métricas como velocidad, energía, distancia o número de partículas sin cambiar de lenguaje.

var nombre = "Luna";
var mensaje = unir("Jugador: ",nombre," · Vida: ",numeroATexto(100));
texto(20,40,mensaje,20,"blanco");

13 · Matemáticas

Las funciones matemáticas cubren trigonometría, aleatoriedad, límites, mapeos y geometría básica.

Trigonometría

sin, cos y tan reciben radianes. senGrados, cosGrados y tanGrados ofrecen directamente la versión en grados.

atan2 produce un ángulo a partir de un vector y anguloHacia calcula el ángulo entre dos puntos.

Rangos

limitar restringe un valor a un intervalo. mapear transforma un valor desde un rango a otro. interpolar mezcla dos valores según un parámetro entre 0 y 1.

aproximar mueve un valor hacia un objetivo por pasos controlados. Estas utilidades son excelentes para cámaras, barras de vida y animaciones suaves.

Movimiento vectorial

vectorX y vectorY transforman un ángulo y una magnitud en componentes X/Y. distancia, distanciaX y distanciaY ayudan a calcular separación entre entidades.

Aleatoriedad

random y randomEntero generan valores aleatorios. elegir y azarDeLista permiten escoger elementos de una colección.

var ang = 35;
var velocidad = 120;
var vx = vectorX(ang,velocidad);
var vy = vectorY(ang,velocidad);
texto(20,40,"vx="+vx+" vy="+vy,18,"cian");

14 · Tiempo y delta-time

La edición orientada a juegos añade tiempo por fotograma para hacer movimiento independiente de la velocidad del monitor.

Variables de tiempo

tiempo entrega milisegundos desde el inicio del programa. segundos entrega el mismo reloj en segundos. frame es el contador de fotogramas.

delta representa el tiempo aproximado transcurrido desde el fotograma anterior y fps estima la frecuencia de actualización.

Por qué usar delta

Mover x = x + velocidad puede producir diferentes velocidades si cambia el framerate. El patrón x += velocidad * delta usa unidades por segundo.

Para físicas simples, multiplicar aceleración y velocidades por delta produce una simulación mucho más estable que depender del número de fotogramas.

Cap

El runtime limita delta a un valor razonable para evitar que una pestaña pausada produzca un salto gigantesco al volver a ejecutarse.

var x=0;
var velocidad=240;
animar {
  x += velocidad * delta;
  si (x > ancho+20) { x=-20; }
  circulo(x,200,20,"amarillo");
}
FLASHIR · 16

15 · Teclado

La entrada por teclado permite construir control directo, menús y juegos arcade.

Estado continuo

tecla_presionada devuelve verdadero mientras la tecla permanece presionada. Es ideal para movimiento continuo con flechas, WASD u otras teclas.

Las teclas de flecha, espacio, enter y letras pueden consultarse mediante su nombre textual.

Eventos de borde

tecla_justo_presionada permite detectar la transición de no presionada a presionada. Es adecuada para saltar, cambiar una pieza, abrir una puerta o avanzar un menú sin repetir la acción cada fotograma.

tecla_justo_soltada cubre la transición inversa.

Patrón recomendado

Separar input de movimiento ayuda a mantener un programa grande legible. Primero actualiza variables de control, después aplica física, finalmente dibuja.

si (tecla_presionada("arrowleft")) { x -= 180 * delta; }
si (tecla_presionada("arrowright")) { x += 180 * delta; }
si (tecla_justo_presionada("space")) { saltar = verdadero; }

16 · Mouse y point-and-click

El mouse proporciona coordenadas actuales, estado de botón y posición del último clic.

Coordenadas

raton_x y raton_y expresan la posición del mouse en coordenadas del Canvas. click_x y click_y guardan la posición del último clic.

raton_presionado permite acciones mientras el botón está pulsado. clic_reciente indica un pulso de clic y evita tener que inventar una máquina de eventos en cada juego.

Zonas

mouseEnRect prueba si el cursor está dentro de un rectángulo. clickEnRect hace la misma prueba usando el último clic y exige además que ese clic sea reciente. clickEnCirculo es la variante circular.

puntoEnRect y puntoEnCirculo también pueden utilizarse con coordenadas arbitrarias, por ejemplo para seleccionar entidades que no sean botones.

si (clickEnRect(100,100,180,60)) {
  mensaje = "Botón activado";
}
si (clickEnCirculo(400,180,35)) {
  mensaje = "Objeto seleccionado";
}
FLASHIR · 18

17 · Colisiones 2D

Las colisiones incorporadas eliminan mucho código repetitivo en juegos.

Rectángulos

colisionRect recibe dos rectángulos expresados como x,y,ancho,alto y devuelve un booleano. Funciona bien para personajes, paredes, plataformas, proyectiles y cajas de UI.

puntoEnRect prueba un punto contra una caja; es útil para mouse, rayos simplificados y selección de objetos.

Círculos

colisionCirculos prueba la distancia entre dos centros frente a la suma de radios. puntoEnCirculo resuelve selección y colisión de puntos con círculos.

Las pruebas no crean físicas automáticas. Solo informan si dos elementos se intersectan; la respuesta, como rebotar, quitar vida o detener movimiento, sigue siendo código Flashir.

Diseño

Para un Tetris se puede evitar colisión geométrica y usar ocupación del tablero. Para un juego de plataformas se suele combinar colisionRect con velocidad vertical y resolución por ejes.

si (colisionRect(px,py,pw,ph,enemigoX,enemigoY,enemigoW,enemigoH)) {
  vida -= 1;
}
si (colisionCirculos(px,py,20,bolaX,bolaY,12)) {
  puntos += 10;
}

18 · Geometría de juegos

Flashir incluye una colección amplia de primitivas para diseñar mundos, personajes, obstáculos y UI.

Primitivas

circulo, rectangulo, rectanguloRedondeado, triangulo, elipse, arco y poligono cubren las formas más frecuentes.

punto, cuadrado, rombo, estrella, corazon y flecha agregan formas semánticas útiles para interfaces, marcadores y prototipos.

Trazos

trazo_iniciar, trazo_linea, trazo_curva y trazo_cerrar permiten construir formas libres con una secuencia de segmentos y curvas cuadráticas.

Tableros

rejilla dibuja una malla regular y resulta útil para editores, mapas y prototipos de juegos de cuadrícula como Tetris.

rejilla(40,"#2a303a",1);
estrella(120,180,5,80,35,"dorado",0);
rombo(300,180,150,100,"morado",15);
corazon(470,180,"relleno","rosa",1.4);

19 · Canvas y estilo

Las funciones de estilo permiten controlar el estado gráfico sin abandonar Flashir.

Relleno y borde

colorRelleno y colorBorde ajustan el color actual. rellenar y borde aplican el estilo a la ruta actual. grosor controla el ancho de trazo.

lineaEstilo cambia cap y join del Canvas.

Texto

fuente cambia la fuente y tamaño actuales. alinear controla la alineación horizontal. medirTexto devuelve el ancho medido de una cadena con la configuración indicada.

texto y textoCentrado siguen siendo las primitivas más sencillas para dibujar etiquetas.

Estado

guardar y restaurar forman una pila de estados de Canvas. Se recomienda envolver transformaciones, opacidad, sombras y colores temporales dentro de esos pares.

resetearTransformacion devuelve la matriz de transformación a la identidad. composicion expone globalCompositeOperation para efectos de composición.

guardar();
sombra("negro",18,5,5);
alinear("center");
fuente(28,"Arial");
colorRelleno("cian");
texto(300,180,"HUD",28,"cian");
restaurar();

20 · Transformaciones y cámara

Trasladar, rotar, escalar y camara permiten pasar de una escena fija a un mundo 2D.

Transformaciones locales

trasladar mueve el origen, rotar gira el Canvas y escalar cambia la escala. guardar y restaurar aíslan la transformación de un objeto concreto.

El patrón permite dibujar un personaje en coordenadas locales y aplicar una rotación sin convertir manualmente todos sus puntos.

Cámara

camara(x,y,zoom) coloca el centro de la vista en una posición del mundo. Esto facilita mapas grandes donde el mundo es mayor que el Canvas.

coordenadaMundoX y coordenadaMundoY convierten coordenadas de pantalla a coordenadas del mundo para responder a clics sobre escenas desplazables.

Visibilidad

rectVisible permite evitar trabajo de renderizado para objetos completamente fuera de la pantalla. En juegos con muchos elementos esto puede ahorrar cálculos.

fondo("#101014");
guardar();
camara(jugadorX,jugadorY,1.4);
rectangulo(-600,-400,1200,800,"#263238");
restaurar();

21 · Color, degradados y sombras

El sistema de color acepta nombres en español, hex y colores CSS válidos para Canvas.

Paleta

La tabla incorporada incluye colores comunes como rojo, azul, verde, amarillo, naranja, morado, rosa, cian, turquesa, coral, lavanda, esmeralda y transparente.

Usar hex permite construir paletas precisas para UI y escenas.

Degradados

fondoDegradado crea un degradado lineal vertical u horizontal. circuloDegradado crea un degradado radial para luces, planetas, orbes y efectos.

Los degradados son parte del dibujo, por lo que pueden combinarse con opacidad y transformaciones.

Sombras

sombra establece color, desenfoque y desplazamiento. quitarSombra restaura una configuración sin sombra. Para no contaminar objetos posteriores, se recomienda restaurar el estado tras un efecto.

fondoDegradado("#07111f","#27336b","vertical");
sombra("negro",24,7,7);
circuloDegradado(300,180,90,"blanco","azul");
quitarSombra();

22 · Imágenes y sprites

imagen permite dibujar recursos remotos dentro del Canvas y sirve como base para prototipos con sprites.

Uso

imagen(url,x,y,w,h) dibuja una imagen escalada. El runtime mantiene una caché de imágenes para evitar recrearlas en cada fotograma.

Como en cualquier navegador, un recurso remoto puede verse afectado por políticas CORS cuando se desea exportar o manipular el contenido.

Sprites

Un sistema de sprites puede representar cada entidad como objeto con posición y luego llamar a imagen para renderizarla. Para animación de cuadros, el lenguaje puede combinar imágenes o diseñar primitivas propias basadas en rectángulos y formas.

Para proyectos educativos, muchos personajes simples pueden dibujarse directamente con Canvas sin depender de recursos externos.

var spriteUrl="https://ejemplo.com/personaje.png";
animar {
  fondo("#101014");
  imagen(spriteUrl,x,y,64,64);
}

23 · Persistencia y sonido

La edición para juegos añade almacenamiento local y un generador de tonos sencillo.

Guardado

guardarDato almacena un valor JSON en localStorage. cargarDato recupera un valor o usa un valor por defecto. borrarDato y existeDato permiten gestionar partidas y configuraciones.

Esto es útil para récords, preferencias, progreso de escenas y valores de simulación.

Audio

sonido(frecuencia,milisegundos,volumen) genera un tono simple mediante Web Audio cuando el navegador permite crear el contexto. Es apropiado para prototipos, UI y eventos cortos.

Para música compleja o sistemas de audio profesionales conviene una arquitectura externa, pero Flashir puede cubrir efectos básicos dentro del archivo único.

Portapapeles y alerta

copiarPortapapeles intenta escribir texto en el portapapeles y alerta muestra un diálogo del navegador. Son herramientas opcionales para prototipos y utilidades.

si (!existeDato("mejor_puntuacion")) { guardarDato("mejor_puntuacion",0); }

si (puntos>mejor) { guardarDato("mejor_puntuacion",puntos); sonido(880,100,0.08); }

24 · El bucle de juego Flashir

El patrón recomendado para juegos es estado → entrada → actualización → renderizado dentro de animar.

Estado

Declara posiciones, velocidades, vida, puntuación, escena, inventario y cualquier lista de entidades fuera de animar.

Ese estado persiste entre fotogramas y es el corazón de la simulación.

Entrada

Consulta teclado y mouse al comienzo del fotograma. Usa teclas continuas para movimiento y teclas “justo” para acciones discretas.

El uso de delta hace que el movimiento dependa del tiempo real y no del número de fotogramas.

Actualización

Aplica aceleración, colisiones, límites, reglas de puntuación y cambios de escena. Si hay muchas entidades, recorre las listas con for o para_cada.

Para mundos grandes, camara y rectVisible separan la lógica del mundo de la ventana visible.

Render

Borra o pinta el fondo, dibuja el mundo con la cámara y finalmente dibuja HUD y mensajes de interfaz.

animar {
  # 1. entrada
  si (tecla_presionada("arrowright")) { x += 240*delta; }
  # 2. actualización
  x=limitar(x,0,ancho);
  # 3. render
  fondo("#101014");
  circulo(x,200,24,"cian");
  texto(20,30,"FPS "+redondear(fps),16,"blanco");
}

25 · Construir un Tetris

Un Tetris educativo puede construirse con una lista plana como tablero y un estado de pieza.

Representación

Un tablero de 10×20 ocupa 200 posiciones. La función celda(x,y) transforma coordenadas en un índice único.

Cada posición guarda una cadena de color o una cadena vacía. Esta representación es simple para comprobar colisiones y dibujar celdas.

Movimiento

La pieza se mueve con izquierda y derecha si la posición destino está libre. La gravedad aumenta con el tiempo y, al tocar otra celda o el suelo, la pieza se fija en el tablero.

Una implementación completa puede ampliar esta base con siete piezas, rotación, limpieza de líneas, siguiente pieza, caída rápida, niveles y puntuación.

Por qué Flashir alcanza el patrón

Las listas dan el almacenamiento; los bucles recorren la cuadrícula; las funciones encapsulan reglas; tecla_justo_presionada detecta entradas discretas; delta implementa gravedad en tiempo real; Canvas dibuja cada bloque.

const columnas=10;
const filas=20;
var tablero=crearLista(columnas*filas,"");
funcion celda(x,y){ retornar y*columnas+x; }
funcion libre(x,y){
  si(x<0 || x>=columnas || y>=filas){ retornar falso; }
  si(y<0){ retornar verdadero; }
  retornar tablero[celda(x,y)]=="";
}

26 · Simulación de partículas

Un simulador de partículas es un excelente ejemplo de que Flashir puede manejar muchos objetos sin una librería externa.

Estado

Cada partícula necesita al menos x, y, vx, vy y radio. Estas propiedades pueden almacenarse en listas paralelas, una representación eficiente y fácil de recorrer.

Una alternativa más expresiva es una lista de objetos, aunque el runtime actual no ofrece un constructor de clase.

Física

La gravedad se suma a vy usando delta. Después se actualiza la posición. Las fronteras reflejan la velocidad y pueden introducir pérdida de energía mediante un factor menor que uno.

Las mismas ideas pueden ampliarse a viento, atracción, resortes, fluidos simplificados y fuerzas entre objetos.

Render

Cada partícula se convierte en un circulo. Elegir puede variar el color. Los datos de diagnóstico pueden mostrarse con texto para observar FPS, cantidad de partículas y energía aproximada.

var n=120;
var x=crearLista(n,0);
var y=crearLista(n,0);
var vx=crearLista(n,0);
var vy=crearLista(n,0);
para(var i=0;i<n;i++){
  x[i]=random(10,ancho-10);
  y[i]=random(10,alto-60);
  vx[i]=random(-80,80);
  vy[i]=random(-50,50);
}

27 · Simuladores físicos

Las funciones de distancia, vectores, interpolación y delta permiten montar simuladores de gravedad, resortes y movimiento.

Gravedad central

Calcula dx y dy desde un objeto hacia un centro, obtén la distancia y normaliza el vector para aplicar una aceleración. Limitar la distancia al cuadrado evita divisiones enormes cuando el objeto se acerca demasiado.

Este patrón permite prototipos orbitales, pozos gravitatorios y visualizaciones de fuerzas.

Resortes

Un resorte puede usar aproximar para alcanzar una posición, o una fórmula simple donde fuerza = rigidez * diferencia. Después la aceleración cambia la velocidad y delta actualiza posición.

La exactitud física no es el objetivo del lenguaje; el foco es ofrecer un modelo pequeño y programable para experimentar.

Interpolación

interpolar, limitar y mapear son muy útiles para cámaras, escalado de señales y visualizaciones.

var dx=objetivoX-x;
var dy=objetivoY-y;
var d=max(1,raiz(dx*dx+dy*dy));
var ax=dx/d*90;
var ay=dy/d*90;
vx+=ax*delta;
vy+=ay*delta;
x+=vx*delta;
y+=vy*delta;

28 · Aventura point-and-click

El estilo de aventura de objetos, pistas y escenas encaja bien con el sistema de clics y objetos.

Máquina de estados

Una variable escena puede representar habitación, pantalla o capítulo. Cada escena define qué objetos son visibles y qué acciones pueden cambiar la historia.

Un objeto jugador puede contener inventario, flags y progreso. Las funciones poner, obtener y tiene permiten modelar llaves, documentos, códigos y pistas.

Para un juego de suspense puede combinarse iluminación mediante degradados, sombras, opacidad, sonidos cortos, animaciones y elecciones temporales. No es necesario copiar la implementación de ningún juego existente; se puede crear una experiencia original con el mismo género de interacción.

30 · Escenas, niveles y checkpoints

Una arquitectura de escenas permite organizar juegos grandes sin cambiar la sintaxis.

Escena

La escena puede ser un número o una cadena. La transición es simplemente una asignación, por ejemplo escena = "bosque".

31 · Patrones de animación

Flashir puede crear animaciones suaves combinando tiempo, trigonometría e interpolación.

Oscilación

senGrados o sin pueden crear movimiento periódico. Un objeto puede subir y bajar con una amplitud determinada sin guardar un contador complejo.

El tiempo global en segundos sirve como fuente continua para ese movimiento.

Ease sencillo

interpolar mezcla valores linealmente. aproximar permite acercarse a un objetivo con velocidad fija. Combinados producen cámaras, barras y objetos UI agradables.

Para efectos visuales, opacidad puede animarse desde un valor hacia otro y luego fijarse en 0 o 1.

rotar cambia el Canvas. Para que un sprite gire alrededor de su centro, se traslada el origen al centro, rota, dibuja en coordenadas locales y luego se restaura.

var flotacion=senGrados(segundos*180)*12;
guardar();
trasladar(300,200+flotacion);
rotar(segundos*90);
rectangulo(-20,-20,40,40,"cian");
restaurar();

32 · Rendimiento y organización

Los proyectos grandes necesitan limitar el trabajo de cada fotograma y mantener funciones pequeñas.

Evitar trabajo innecesario

No redibujes recursos o listas grandes si el estado no cambió cuando no sea necesario. rectVisible ayuda a descartar objetos fuera de pantalla.

Para muchos objetos, listas paralelas pueden ser más sencillas y rápidas que estructuras profundamente anidadas.

Separación

Divide el código en funciones: actualizarEntrada, actualizarFisica, actualizarEnemigos, dibujarMundo y dibujarHUD. Aunque todo siga dentro del mismo archivo, el programa se vuelve más manejable.

Usa nombres consistentes y evita que una misma función altere demasiados sistemas.

Seguridad

Los bucles para y mientras tienen una protección contra cantidades excesivas de iteraciones. La recursión tiene un límite de profundidad. Esto no reemplaza el buen diseño, pero evita algunos errores catastróficos.

animar {
  actualizarEntrada();
  actualizarFisica();
  actualizarEnemigos();
  dibujarMundo();
  dibujarHUD();
}

33 · Errores y depuración

La consola del editor muestra errores de sintaxis y de ejecución.

Sintaxis

Un error de sintaxis aparece cuando el lexer no reconoce un carácter, falta un delimitador o el parser no encuentra la estructura esperada.

Los mensajes incluyen una aproximación de línea para localizar el problema.

Ejecución

Un error de ejecución puede ser una variable inexistente, una función desconocida o una operación incompatible con el tipo de valor. Cuando ocurre dentro de animar, la animación se detiene y el mensaje aparece en consola.

Estrategia

Prueba primero una versión pequeña. Usa imprimir para verificar coordenadas, estados y longitudes de listas. Después vuelve a añadir el renderizado.

Para juegos, imprime temporalmente escenas, vidas, velocidades y colisiones antes de buscar un fallo gráfico.

imprimir("escena="+escena);
imprimir("jugador="+jugador.x+","+jugador.y);
imprimir("enemigos="+lista_longitud(enemigos));

34 · Gramática compacta

Esta página resume la forma sintáctica que otra implementación de Flashir debe reconocer.

Producciones

Programa = sentencia*. Bloque = { sentencia* }. Declaración = (var|let|const) IDENT = expresión. Función = funcion IDENT (parametros) bloque.

Las sentencias de control usan si, sino, repetir, para, mientras, para_cada, animar, retornar, romper y continuar.

Las expresiones incluyen literales, listas, objetos, llamadas, índices, propiedades, operadores aritméticos, comparaciones, lógica y ternario.

Literales

Número: entero o decimal. Texto: "..." con escapes básicos. Booleanos: verdadero y falso. Nulo: nulo o null en la versión actual.

Lista: [expresión, ...]. Objeto: {clave: expresión, ...}.

Asignaciones

Variable: nombre = expresión y variantes compuestas. Propiedad: objeto.propiedad = expresión y variantes compuestas. Lista: nombre[indice] = expresión.

programa := sentencia*
sentencia := declaracion | funcion | condicional | repeticion | animar | retorno | ruptura | asignacion | expresion
declaracion := (var|let|const) IDENT "=" expresion
lista := "[" (expresion ("," expresion)*)? "]"
objeto := "{" (clave ":" expresion ("," clave ":" expresion)*)? "}"
expresion := ternario
ternario := or ("?" expresion ":" expresion)?

40 · Cierre y filosofía

Flashir busca que la distancia entre una idea y una escena interactiva sea pequeña.

Qué recordar

Las listas son tus tableros y colecciones. Los objetos son tus entidades. Las funciones son tus sistemas. animar es tu bucle de juego. Canvas es tu salida visual.

delta hace que el tiempo sea una magnitud explícita. Las colisiones convierten geometría en reglas. La cámara separa mundo y pantalla. El almacenamiento permite continuidad entre sesiones.

Hasta dónde llegar

Con estas herramientas se pueden construir prototipos jugables de Tetris, shooters sencillos, juegos de plataformas, simuladores físicos, editores de mapas, aventuras point-and-click, sistemas de partículas, interfaces y visualizaciones.

Un proyecto puede crecer sin abandonar Flashir: cuando falte una primitiva concreta, puede encapsularse la combinación de primitivas existentes en una funcion propia. Si falta una capacidad del runtime, entonces el siguiente paso es ampliar el intérprete, no inventar una sintaxis paralela.

Principio

Es mejor un lenguaje coherente con muchas combinaciones que un catálogo enorme de comandos desconectados. La potencia de Flashir está en que las mismas piezas sirven para dibujo, juego y simulación.

# La receta
funcion juego(){
  # estado + entrada + actualización + render
}
animar {
  juego();
}
