El lenguaje Flashir

Estructura básica

Cada instrucción termina en ; (opcional al final de línea). Los comentarios empiezan con # o //.

fondo("#101014"); circulo(300, 200, 80, "azul"); texto(40, 40, "¡Hola!", 28, "blanco");

Variables

var x = 10; x = x + 5; x += 1;

Control de flujo

si (x > 100) { circulo(x, 100, 20, "rojo"); } sino { circulo(x, 100, 20, "azul"); } repetir(10) { circulo(random(0, ancho), random(0, alto), 8, "rosa"); } para (var i = 0; i < 5; i++) { circulo(i * 60 + 40, 200, 20, "verde"); } mientras (x < 500) { x = x + 10; } para_cada (var item en [10, 20, 30]) { imprimir(item); }

Dentro de cualquier bucle (repetir, para, mientras, para_cada) podés usar romper; para salir del bucle y continuar; para saltar a la siguiente vuelta.

Funciones propias

Podés definir tus propias funciones con funcion y devolver un valor con retornar. Se pueden llamar a sí mismas (recursión).

funcion doble(n) { retornar n * 2; } funcion factorial(n) { si (n <= 1) { retornar 1; } retornar n * factorial(n - 1); } imprimir(doble(21)); imprimir(factorial(5));

Listas

Una lista se escribe entre corchetes. Se accede e indexa con lista[indice] (los índices negativos cuentan desde el final).

var colores = ["rojo", "verde", "azul"]; imprimir(colores[0]); colores[1] = "amarillo"; imprimir(colores[-1]); para_cada (var c en colores) { imprimir(c); }

Animación

Todo lo que pongas dentro de animar { ... } se repite en cada fotograma (como una película).

var x = 0; animar { fondo("#101014"); x = x + 3; circulo(x, 200, 20, "amarillo"); }

Flashir ampliado

Esta edición conserva el núcleo original y agrega let/const, nulo, objetos literales, propiedades con punto, ternario, introspección, utilidades de texto/listas y primitivas gráficas.

const jugador = {nombre: "Luna", puntos: 120}; jugador.puntos += 10; texto(30,60,jugador.nombre,28,"cian"); texto(30,100,jugador.puntos >= 100 ? "Experto" : "Inicial",22,"amarillo");
tipo(v)numero, texto, booleano, lista, objeto o nulo.
objeto()Crea un objeto vacío.
poner / obtener / eliminarGestionan propiedades.
claves / valores / tieneInspeccionan objetos.
recortar / separar / empiezaCon / terminaConTexto.
subLista / copiarLista / lista_indice / lista_reemplazarListas.
punto / cuadrado / rombo / estrella / corazon / flechaGeometría adicional.
rejilla / medirTexto / fuente / alinear / grosorComposición.
colorRelleno / colorBorde / rellenar / bordeCanvas avanzado.
resetearTransformacion / composicionRenderizado avanzado.

El ternario usa condición ? valor_si : valor_no. Los objetos usan {clave: valor} y objeto.clave.

Arquitectura

Flashir sigue el flujo lexer → parser → AST → intérprete → Canvas 2D. La consola distingue errores de sintaxis y ejecución.

Colores

Podés usar nombres en español, un código hex como "#4da3ff", o cualquier color CSS como "tomato".
