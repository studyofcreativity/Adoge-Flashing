Identidad

flashir.html es una aplicación web autocontenida que contiene editor, Canvas, consola, ejemplos e intérprete. Este documento explica el programa anfitrión; DocFlashir explica la sintaxis del lenguaje.

DOCFLASHIRINFO · 3

Interfaz

La barra superior contiene marca, ejemplos, Ejecutar, Detener, Descargar PNG, Lenguaje y Documentación. El área principal divide editor y resultado, y la consola queda debajo del Canvas.

DOCFLASHIRINFO · 4

Editor

El editor es un textarea de fuente monoespaciada. Conserva saltos de línea y espacios. Ctrl+Enter ejecuta el código.

DOCFLASHIRINFO · 5

Ejecutar

Ejecutar detiene la animación previa, reinicia scopes, funciones, frames y reloj; después tokeniza, analiza y ejecuta. Si existe animar, comienza el ciclo de frames.

DOCFLASHIRINFO · 6

Detener

Detener cancela requestAnimationFrame activo. El código permanece en el editor y el Canvas conserva su estado hasta la siguiente ejecución o dibujo.

DOCFLASHIRINFO · 7

Ejemplos

Hay ejemplos de dibujo, azar, rebote, mouse, trazos, funciones, listas, teclado, degradados, polígonos, objetos, formas, Tetris, partículas, aventura, gravedad y UI.

DOCFLASHIRINFO · 8

Tamaño visual vs lógico

CSS puede reducir o ampliar el Canvas dentro de la ventana. Las coordenadas del lenguaje siguen usando canvas.width y canvas.height. El cálculo del mouse compensa la escala visual.

DOCFLASHIRINFO · 9

Teclado

keydown y keyup mantienen un conjunto de teclas presionadas. tecla_presionada consulta estado continuo; tecla_justo_presionada y tecla_justo_soltada consultan transiciones.

DOCFLASHIRINFO · 10

Mouse

mousemove actualiza raton_x/y; click actualiza click_x/y y activa un pulso de clic. Las funciones mouseEnRect, clickEnRect y clickEnCirculo facilitan interacción.

DOCFLASHIRINFO · 11

Animación

requestAnimationFrame controla el ciclo. delta expresa segundos aproximados desde el frame anterior, fps estima frecuencia y frame cuenta frames. El runtime limita el delta para estabilizar pausas largas.

DOCFLASHIRINFO · 12

Cámara

camara(x,y,zoom) cambia la transformación del Canvas. mundoX/Y y pantallaX/Y convierten coordenadas. resetearTransformacion restaura identidad.

DOCFLASHIRINFO · 13

Colisiones

colisionRect compara dos cajas; colisionCirculos compara dos círculos; puntoEnRect y puntoEnCirculo prueban pertenencia. El runtime no aplica automáticamente físicas.

DOCFLASHIRINFO · 14

Imágenes y CORS

imagen() carga URLs y usa una caché por recurso. El navegador decide si un recurso externo es compatible con Canvas y exportación mediante sus políticas CORS.

DOCFLASHIRINFO · 15

Audio

tono y bip usan Web Audio para sonidos simples. El navegador puede exigir interacción del usuario antes de permitir audio; no es un sistema musical completo.

DOCFLASHIRINFO · 16

Persistencia

guardarDato, cargarDato, existeDato y borrarDato usan localStorage. Es almacenamiento local del navegador, no una base de datos de servidor.

DOCFLASHIRINFO · 17

Rendimiento

El rendimiento práctico depende del navegador, CPU, GPU, cantidad de objetos, paths, sombras, texto y operaciones por frame. No existe un único número universal de entidades soportadas.

DOCFLASHIRINFO · 18

Protecciones

Los bucles para/mientras tienen guardas contra demasiadas iteraciones y las funciones recursivas tienen un límite de profundidad. Son protecciones contra errores accidentales.

DOCFLASHIRINFO · 19

Seguridad y límites

Flashir no expone acceso arbitrario al sistema operativo ni evalúa JavaScript del usuario como código Flashir. Los recursos del navegador siguen sujetos a sus propias políticas.
